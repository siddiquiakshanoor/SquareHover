HTML Basics

Introduction

HTML is the standard language for creating web pages. It uses tags to structure content.

Headings

Headings range from <h1> (most important) to <h6> (least important). They help organize content.

Paragraphs

Paragraphs are written using the <p> tag. They are used to add descriptive text.

Images

Images can be added using the <img> tag. Always include an alt attribute for accessibility.

Links

Links are created using the <a> tag. You can open them in a new tab using target="_blank".
